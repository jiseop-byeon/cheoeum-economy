# 경제개념학습

정책과 시장을 읽기 위한 기초. 경제를 처음 공부하는 사람을 위한 정적 학습 사이트입니다.

강의 본문은 설명하는 말투(합니다)이고, 용어 카드는 짧게 짚는 말투(해요)입니다. 강의와 사전을 일부러 다른 층으로 두었습니다.

강의 16개는 다섯 묶음입니다. 생활(생산, 물가, 일자리, 가계), 돈의 값(금리, 은행, 한국은행), 나라와 세계(경기, 재정, 환율), 시장(채권, 주식, 집, 가상자산), 읽는 법(발표를 읽는 순서, 돈을 넣기 전의 네 칸). 각 강의는 그 자리에서 계산을 직접 합니다. 각 강의에 검산한 계산과, 숫자만 바꾼 확인 문제가 있습니다. 용어 787개는 카드입니다. 표제어는 한국은행이 2026년 1월에 발간한 『경제금융용어 800선』을 범위로 삼았습니다. 설명 문장은 그 책의 해설이 아니며, 이 사이트가 처음 읽는 사람을 위해 따로 썼습니다.

금리, 예금보호, 통계처럼 날짜가 있는 숫자는 그 발표일의 공표 자료입니다. 다음 발표가 나오면 [출처](https://jiseop-byeon.github.io/cheoeum-economy/#/sources)의 기관 페이지가 우선합니다. 한국은행, 통계청, 기획재정부, 금융위원회, 금융감독원, 예금보험공사, 한국거래소, 국토교통부 실거래가, 한국부동산원, 미국 연준, IMF, OECD, BIS, 유럽중앙은행, 세계은행을 연결해 두었습니다.

이 사이트는 매매를 권하지 않습니다. 종목, 대출 한도, 세금, 상품 약관은 해당 기관과 금융회사의 최신 자료를 따르세요.

## 로컬에서 보기

```bash
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다. 주소 해시(`#/learn`, `#/terms`, `#/review`)로 이동합니다. 읽음과 복습 표시는 이 브라우저의 `localStorage`에만 남습니다.

빌드 단계는 없습니다. `index.html`이 `css/site.css`, `js/course.js`, `js/terms.js`, `js/app.js`를 그대로 읽습니다.

색은 `css/site.css` 맨 위 두 블록에만 있습니다. `:root`가 기본(어두운 남색), `:root[data-theme="light"]`가 밝은 짝입니다. 상단의 밝게/어둡게 버튼이 둘을 바꾸고, 고른 쪽은 이 브라우저에 남습니다.
